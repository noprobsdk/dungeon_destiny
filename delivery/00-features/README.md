# Released Features

This directory contains one record for each released and verified Feature.

Feature files are not created here when development starts. Active work belongs in GitHub. A Feature enters this directory only after deployment and verification.

## Required Feature record

```markdown
# FEAT-00001 — Feature title

Status: Released
Released in: REL-0001
Released date: YYYY-MM-DD
GitHub issue: #000
Pull request: #000
Verified build: build identifier

## Delivered capability

Describe the behaviour that demonstrably exists.

## Acceptance evidence

Link each acceptance criterion to its verification evidence.

## Delivery documentation

List the delivery system documents updated by this Feature.

## Design sources

List the canonical `doc/` sources and the design baseline commit used when the Feature was approved.

## Known limitations

Record limitations that remain in the released implementation.
```
