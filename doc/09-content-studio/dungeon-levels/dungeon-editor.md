# Dungeon Level editor

The editor must support creating, duplicating, versioning, validating, reviewing, locking, and publishing Dungeon Levels.

It must display ordered Stages, maze reference, fixed DL XP Budget, assigned enemy versions, centrally derived Monster XP, unlock conditions, Tactical Pause unlocks, and release membership.

AI may propose initial layouts and assignments, but it cannot approve, lock, or publish content.
