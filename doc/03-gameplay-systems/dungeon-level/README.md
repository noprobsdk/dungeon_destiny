# Dungeon Level gameplay systems

This area defines the gameplay systems that operate while the Hero is inside an active Dungeon Level.

Each system is documented separately so that shared Character Modes, Hero behavior, enemy behavior, Threat Sources, Tactical Pause, objectives, encounters, rewards, and other Dungeon Level mechanics do not become mixed into one specification.

## Systems

- [Character Modes](character-modes.md) — shared Peace and Threat contract for runtime characters.
- [Hero States](hero-states.md) — Hero-specific targeting, attacks, weapons, and state transitions.
- [Enemy States](enemy-states.md) — enemy awareness, combat behavior, disengagement, and Threat Source relationships.
- [Threat Sources](threat-sources.md)
- [Traits and Stage offers](traits-and-stage-offers.md)
- [Tactical Pause](tactical-pause.md)
