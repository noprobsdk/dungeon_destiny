# Asset registries

Content Studio maintains separate registries for:

- Body Bases;
- Rig Profiles;
- Equipment assets;
- weapon families and sockets;
- Animation Sets;
- Grip Profiles;
- materials and appearance profiles;
- composed Runtime Characters.

Every relationship is validated against the 3D production contracts. A file existing in storage does not make it approved or compatible.
