# Content lifecycle

`Draft → Review → Locked → Published → Retired`

- **Draft:** editable and incomplete content.
- **Review:** candidate undergoing rules, quality, compatibility, and balance review.
- **Locked:** immutable release candidate content.
- **Published:** included in an immutable release manifest.
- **Retired:** retained for traceability but unavailable to new releases.

Corrections to Locked or Published content create a new version. Content Studio must never modify published records in place.
