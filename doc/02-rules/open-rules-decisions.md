# Open rules decisions

| Decision | Status | Required outcome |
|---|---|---|
| Tactical Pause frequency and exact recharge curve | Open | Tune base recharge and Struggle Meter modifiers through playtesting. |
| Actions available during TP in each release | Open | Bind actions to release capabilities without fabricating unavailable equipment or spells. |
| Queued spell resolution after TP | Open | Define simultaneous versus ordered execution and interruption. |
| Trait inspiration from official rules | Open | Keep temporary Traits distinct from permanent Class features and Feats. |
| Future multiplayer authority | Deferred | Define server authority only if multiplayer enters an approved release. |
