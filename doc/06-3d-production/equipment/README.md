# 3D equipment

Equipment is validated as a matrix, not as isolated attractive assets.

- Rigid equipment uses sockets and Grip Profiles.
- Skinned equipment uses exact Body Base/Rig Profile variants.
- Hide regions prevent covered body parts from clipping through armor.
- Gloves and gauntlets require special hand/finger review.
- Every published combination must have recorded evidence.

See [Equipment compatibility matrix](equipment-compatibility-matrix.md).
