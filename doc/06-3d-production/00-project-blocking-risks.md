# Project-blocking 3D risks

| Risk | Consequence | Required proof |
|---|---|---|
| Unstable humanoid rig | Animation and equipment cannot be reused. | Approved Rig Profile and rest pose. |
| Incorrect hands/finger axes | Weapons cannot be held naturally. | Open, fist, and Ø29 mm grip gates. |
| Incompatible skinned equipment | Armor clips or deforms unpredictably. | Complete equipment combination matrix. |
| Animation/body mismatch | Broken shoulders, wrists, feet, or weapon alignment. | Standard action-set deformation review. |
| Blender/Godot mismatch | Approved source looks wrong at runtime. | Identical standardized test scene. |
| Excessive asset cost | Mobile memory and performance failure. | Measured polygon, material, texture, bone, and FPS budgets. |
| Unbounded experimentation | Time and budget consumed without production asset. | Timeboxed go/no-go and fallback decision. |

No asset is `READY` because it looks correct in one still image. Readiness requires recorded gate evidence.
