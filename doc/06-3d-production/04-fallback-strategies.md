# 3D fallback strategies

## Plan A — Fully modular

Reusable Body Bases, skinned equipment variants, shared Animation Sets, separate weapons, and runtime composition.

## Plan B — Semi-modular

One validated body/outfit assembly per archetype with separate weapons and a smaller Animation Set matrix. This is the preferred fallback if skinned modular equipment remains unstable.

## Plan C — Fixed Runtime Characters

One preassembled character per approved loadout. Content Studio selects complete Runtime Characters rather than composing armor pieces. Weapons can remain separate where validated.

The fallback changes production scope, not gameplay rules. Content Studio must expose only combinations supported by the selected strategy.
